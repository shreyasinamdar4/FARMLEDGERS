# FARMLEDGERS
AGRI SUPPLY CHAIN ENHANCEMENT PROJECT.

This project introduces a blockchain-based transparent supply chain system designed to solve information asymmetry and unfair pricing in agriculture. By integrating Hyperledger Fabric, IoT sensors, and RFID tags, the prototype ensures end-to-end traceability and real-time quality monitoring from farm to consumer. The solution features a data-driven dynamic pricing mechanism and a Cyber-Physical System (CPS) architecture to synchronize physical assets with digital records, ultimately reducing post-harvest losses and eliminating intermediary manipulation. This secure, scalable platform empowers farmers with predictive decision support while providing consumers with verified product provenance.
